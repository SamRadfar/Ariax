# openGym فارسی

**[English](README.md) · فارسی**

ساخته‌شده و نگهداری‌شده توسط **[آرتا (Jenesyx)](https://github.com/Jenesyx)** · [مخزن پروژه](https://github.com/Jenesyx/opengym-fa)

openGym یک وب‌اپلیکیشن رایگان و متن‌باز برای برنامه‌ریزی تمرین، ثبت ست‌ها، پیگیری وزن بدن و مشاهده پیشرفت ورزشی است. می‌توانید آن را روی سیستم یا سرور خودتان اجرا کنید؛ داده‌ها در اختیار خودتان می‌مانند و هیچ اشتراک یا تبلیغی وجود ندارد.

# اگر توسعه‌دهنده نیستید، این بخش را بخوانید

برای آنلاین‌کردن openGym لازم نیست برنامه‌نویس باشید یا سرور شخصی داشته باشید. فقط به یک حساب
رایگان GitHub، یک حساب در سرویس میزبانی و یک دستیار هوش مصنوعی نیاز دارید که بتواند روی مخزن
GitHub شما کار کند. هوش مصنوعی انتشار را آماده می‌کند و سرویس میزبانی سایت را آنلاین نگه می‌دارد.

> **نکته مهم:** برای نسخه کامل برنامه باید میزبانی‌ای انتخاب شود که از **Docker و فضای ذخیره‌سازی
> دائمی** پشتیبانی کند؛ مانند Railway یا Render. openGym فقط یک صفحه استاتیک نیست: API آن پروفایل،
> Passkey و تاریخچه تمرین را ذخیره می‌کند. انتشار معمولی روی Vercel یا Netlify فقط فرانت‌اند را
> منتشر می‌کند و **نصب کامل محسوب نمی‌شود**. فقط زمانی از این دو سرویس استفاده کنید که یک
> توسعه‌دهنده یا هوش مصنوعی، API و ذخیره‌سازی دائمی را نیز برای آن‌ها بازطراحی و بررسی کند.

## ۱. یک نسخه از پروژه را وارد حساب GitHub خود کنید

1. وارد [GitHub](https://github.com/) شوید.
2. مخزن [Jenesyx/opengym-fa](https://github.com/Jenesyx/opengym-fa) را باز کنید.
3. در بالای سمت راست صفحه روی **Fork** بزنید.
4. در صفحه بعد، حساب خودتان را به‌عنوان **Owner** انتخاب کنید، نام `opengym-fa` را نگه دارید و
   **Create fork** را بزنید.
5. صبر کنید تا آدرس `https://github.com/YOUR-NAME/opengym-fa` باز شود.

Fork همان نسخه‌ای است که به حساب شما اضافه می‌شود؛ لازم نیست دوباره فایل‌ها را آپلود کنید.

## ۲. از هوش مصنوعی بخواهید سایت را آنلاین کند

ساده‌ترین روش مطمئن این است که دسترسی مخزن Forkشده را به یک دستیار هوش مصنوعی بدهید و از آن
بخواهید **کل برنامه Docker** را روی یک میزبان مدیریت‌شده منتشر کند. [Railway](https://railway.com/)
و [Render](https://render.com/) نمونه‌های مناسب هستند؛ کامپیوتر آنلاین، آدرس HTTPS و دیسک دائمی
را در اختیار شما می‌گذارند و نیازی به مدیریت سرور فیزیکی ندارید. سرویس یا دیسک دائمی ممکن است
پولی باشد؛ قبل از تأیید، قیمت روز سرویس را بررسی کنید.

پرامپت زیر را کپی کنید، `YOUR-NAME` را با نام کاربری GitHub خودتان جایگزین کنید و آن را به Codex،
ChatGPT، Claude یا دستیار دیگری بدهید که امکان ویرایش مخزن شما را دارد:

```text
من توسعه‌دهنده نیستم. لطفاً Fork من از openGym-fa را آنلاین کن و هر بار فقط یک مرحله ساده به من بگو:
https://github.com/YOUR-NAME/opengym-fa

نسخه کامل برنامه را می‌خواهم: فرانت‌اند، API مبتنی بر Node، تصاویر تمرین، ورود با Passkey و
ذخیره دائمی اطلاعات تمرین. یک میزبان Docker مدیریت‌شده مانند Railway یا Render انتخاب کن.
من سرور ندارم. پیش از انتخاب پلن پولی، قیمت فعلی را بگو و از من تأیید بگیر.

شرایط:
1. فقط روی Fork من کار کن و رابط فارسی و انگلیسی را حفظ کن.
2. فقط فرانت‌اند را روی Vercel یا Netlify منتشر نکن. اگر روی یکی از آن‌ها اصرار کردم، توضیح بده
   که API و ذخیره‌سازی دائمی باید منتقل شوند و نتیجه کامل را بررسی کن.
3. تنظیمات انتشار لازم برای میزبان انتخاب‌شده را ایجاد یا اصلاح کن.
4. فضای ذخیره‌سازی دائمی متصل کن و API را طوری تنظیم کن که از /data استفاده کند. پروفایل‌ها،
   Passkeyها و تاریخچه تمرین باید پس از restart و انتشار مجدد باقی بمانند.
5. برای RP_ID فقط hostname نهایی و برای ORIGIN آدرس کامل HTTPS را قرار بده.
6. فایل .env، session secret، Passkey، cookie، data/db.json یا فایل پشتیبان را منتشر یا commit نکن.
7. انتشار خودکار از Fork من را فعال کن، اما پیش از تغییر هزینه، دامنه یا دسترسی از من اجازه بگیر.
8. بررسی کن صفحه عمومی HTTP 200 می‌دهد و /api/health یک JSON شامل ok: true برمی‌گرداند.
9. یک بار سرویس را restart یا redeploy کن و مطمئن شو پروفایل و داده آزمایشی حذف نشده‌اند.
10. آدرس نهایی سایت، ساخت اولین پروفایل، خصوصی‌کردن ثبت‌نام با دعوت‌نامه، نصب روی گوشی،
    پشتیبان‌گیری از /data و انتشار تغییرات بعدی GitHub را به من آموزش بده.

تا زمانی که فرانت‌اند، API، ورود Passkey روی HTTPS، تصاویر و ماندگاری داده بررسی نشده‌اند، اعلام
موفقیت نکن. اگر لازم است روی چیزی کلیک کنم، نام دقیق دکمه و محل آن را در صفحه فعلی بگو.
```

## ۳. سایت آنلاین را باز و استفاده کنید

پس از دریافت آدرس نهایی `https://...` از هوش مصنوعی:

1. سایت را باز کنید و **Create profile** را بزنید.
2. با Face ID، اثر انگشت، Windows Hello یا PIN دستگاه یک **Passkey** بسازید. Passkey جای رمز عبور
   سنتی را می‌گیرد.
3. برای فارسی، به **Settings → General → Language → فارسی** بروید.
4. در **Plan** یک روتین بسازید و آن را به روزهای هفته اختصاص دهید.
5. در روز تمرین، دکمه مرکزی **Start** را بزنید.
6. مرتب از **Settings → Data → Export backup** فایل پشتیبان بگیرید.
7. برای نصب مانند اپ: در Android/Chrome گزینه **⋮ → Add to Home screen** و در iPhone/Safari
   گزینه **Share → Add to Home Screen** را بزنید.

خود آدرس سایت **رمز عبور نیست**. اگر محافظ دسترسی یا ثبت‌نام فقط با دعوت‌نامه فعال نباشد، هر کسی
که آدرس را بداند می‌تواند صفحه ثبت‌نام را باز کند. ابتدا پروفایل خودتان را بسازید و سپس از هوش
مصنوعی بخواهید در صورت نیاز دسترسی را invite-only کند.

## ۴. بعداً نسخه خودتان را ویرایش کنید

- در صفحه Fork خودتان در GitHub کلید **`.`** را بزنید تا ویرایشگر مرورگر GitHub باز شود؛ یا مخزن
  را در ابزار هوش مصنوعی دلخواه خود باز کنید.
- تغییر موردنظر را به هوش مصنوعی بگویید، آن را بررسی کنید و اجازه دهید تغییر را در Fork شما
  **commit و push** کند.
- اگر انتشار خودکار متصل باشد، سرویس میزبانی پس از Push سایت را دوباره می‌سازد.
- هیچ‌وقت `.env`، پوشه `data/`، فایل پشتیبان، Passkey یا مقدار محرمانه را در GitHub آپلود نکنید.

اگر فقط می‌خواهید برنامه را روی یک کامپیوتر امتحان کنید و سایت عمومی لازم ندارید، انتشار ابری را
انجام ندهید و بخش [نصب سریع با Docker](#نصب-سریع-با-docker) را بخوانید.

رابط کاربری فارسی کامل و راست‌به‌چپ است. برای فعال‌کردن آن به **Settings → General → Language → فارسی** بروید. توضیحات حرکات ورزشی فعلاً از دیتاست انگلیسی نمایش داده می‌شوند، اما تمام بخش‌های رابط کاربری فارسی هستند.

## نصب سریع با Docker

### پیش‌نیاز

[Docker Desktop](https://docs.docker.com/get-docker/) یا Docker Engine همراه با افزونه Compose را نصب کنید.

### Linux یا macOS

```bash
git clone https://github.com/Jenesyx/opengym-fa.git
cd opengym-fa
cp .env.example .env
docker compose up -d --build
```

### Windows PowerShell

```powershell
git clone https://github.com/Jenesyx/opengym-fa.git
Set-Location opengym-fa
Copy-Item .env.example .env
docker compose up -d --build
```

پس از پایان ساخت، آدرس **http://localhost:8080** را باز کنید. در اجرای اول حدود ۱۴۰ مگابایت تصویر و GIF تمرین‌ها دانلود می‌شود.

### بررسی نصب

```bash
docker compose ps
curl http://localhost:8080/api/health
```

پاسخ API باید شامل `"ok": true` باشد. برای مشاهده لاگ‌ها:

```bash
docker compose logs -f
```

برای توقف برنامه:

```bash
docker compose down
```

این دستور داده‌های شما را حذف نمی‌کند؛ اطلاعات در پوشه `data/` باقی می‌مانند.

## روش استفاده از وب‌سایت

### ۱. ساخت پروفایل یا ورود به حالت مهمان

- برای همگام‌سازی داده‌ها بین دستگاه‌ها، **Create profile** را انتخاب و با اثر انگشت، Face ID، Windows Hello یا Passkey پروفایل بسازید.
- برای استفاده فقط روی همان مرورگر، **Continue without account** را انتخاب کنید.

### ۲. فعال‌کردن زبان فارسی

وارد **Settings → General → Language** شوید و **فارسی** را انتخاب کنید. جهت صفحه بلافاصله راست‌به‌چپ می‌شود.

### ۳. ساخت برنامه تمرینی

1. بخش **Plan / برنامه** را باز کنید.
2. یک روتین جدید بسازید یا برنامه آماده Push / Pull / Legs را بارگذاری کنید.
3. تمرین‌ها، تعداد ست، تکرار و وزن اولیه را اضافه کنید.
4. هر روتین را به روزهای هفته اختصاص دهید.

### ۴. اجرای تمرین

1. دکمه مرکزی **Start / شروع** را بزنید.
2. در صورت نیاز وزن بدن خود را ثبت کنید.
3. ست‌ها را به‌ترتیب انجام دهید و هر ست کامل‌شده را علامت بزنید.
4. از زمان‌سنج استراحت، سوپرست، تمرین زمان‌دار و ثبت RIR/RPE استفاده کنید.
5. در پایان **Finish workout / پایان تمرین** را بزنید.

### ۵. مشاهده پیشرفت

- در **Stats / آمار** نمودار وزن، رکوردها، حجم تمرین، 1RM تخمینی و تعادل عضلات را ببینید.
- در **History / تاریخچه** جزئیات تمرین‌های قبلی را بررسی یا اصلاح کنید.

### ۶. پشتیبان‌گیری

هر کاربر می‌تواند از **Settings → Data → Export backup (JSON)** یک فایل پشتیبان بگیرد.

مدیر سرور باید از کل پوشه `data/` نسخه پشتیبان داشته باشد؛ این پوشه شامل پروفایل‌ها، تاریخچه تمرین و تنظیمات سرور است. فایل‌های داخل آن را عمومی نکنید.

## نصب روی گوشی یا دسکتاپ

openGym یک PWA است. ابتدا نسخه HTTPS وب‌سایت را باز کنید، سپس:

- **Android / Chrome:** منوی **⋮ → Add to Home screen**
- **iPhone یا iPad / Safari:** گزینه **Share → Add to Home Screen**
- **Chrome یا Edge دسکتاپ:** آیکن نصب در نوار آدرس

Passkey و اعلان‌ها فقط روی `http://localhost` یا یک دامنه HTTPS کار می‌کنند. مرورگرها WebAuthn را روی آدرس ساده شبکه مانند `http://192.168.x.x` قبول نمی‌کنند؛ در چنین آدرسی فقط حالت مهمان قابل استفاده است.

## اجرای پروژه برای توسعه

برای تغییر کد، Node.js نسخه `20.19+` یا `22.12+` لازم است:

```bash
git clone https://github.com/Jenesyx/opengym-fa.git
cd opengym-fa
npm install
npm run dev
```

آدرس فرانت‌اند در ترمینال نمایش داده می‌شود و معمولاً **http://localhost:5173** است. این دستور فرانت‌اند، API و سرور محلی تصاویر را هم‌زمان اجرا می‌کند و اگر پورت API اشغال باشد، پورت آزاد دیگری را خودکار انتخاب می‌کند.

دستورهای بررسی پروژه:

```bash
npm test
npm run build
```

## انتشار روی دامنه و HTTPS

برای استفاده از Passkey روی گوشی، برنامه را پشت Cloudflare Tunnel، Caddy، Traefik، nginx یا Nginx Proxy Manager قرار دهید و یک دامنه HTTPS داشته باشید.

فایل `.env` را تنظیم کنید:

```dotenv
RP_ID=gym.example.com
ORIGIN=https://gym.example.com
WEB_PORT=8080
RP_NAME=openGym
```

- مقدار `RP_ID` فقط نام میزبان است و نباید `https://` یا مسیر داشته باشد.
- مقدار `ORIGIN` باید آدرس کامل و دقیق وب‌سایت باشد.
- تغییر `RP_ID` پس از ساخت حساب، Passkeyهای قبلی را نامعتبر می‌کند.
- فایل `.env` و پوشه `data/` را در Git یا پیام عمومی قرار ندهید.

پس از تغییر تنظیمات:

```bash
docker compose up -d --build
```

راهنمای کامل‌تر: [docs/SELF_HOSTING.md](docs/SELF_HOSTING.md)

## رفع خطاهای رایج

| مشکل | راه‌حل |
|---|---|
| `npm install` در ریشه خطا می‌دهد | Node.js سازگار را نصب و دوباره `npm install` را در پوشه اصلی پروژه اجرا کنید. |
| پورت 8080 اشغال است | در `.env` مقدار `WEB_PORT` و سپس پورت داخل `ORIGIN` را تغییر دهید. |
| Passkey روی گوشی باز نمی‌شود | از دامنه HTTPS استفاده کنید؛ IP شبکه با HTTP برای WebAuthn معتبر نیست. |
| ورود با خطای verification مواجه می‌شود | `RP_ID` و `ORIGIN` را دقیقاً با آدرس مرورگر یکسان کنید و سرویس را دوباره اجرا کنید. |
| تصاویر تمرین نمایش داده نمی‌شوند | `docker compose logs media` را بررسی و `docker compose up -d` را دوباره اجرا کنید. |
| سرویس بالا نمی‌آید | ابتدا `docker compose ps` و سپس `docker compose logs <service>` را بررسی کنید. |

## پرامپت آماده برای راه‌اندازی با هوش مصنوعی

برای انتشار بدون کدنویسی از Fork خودتان، از پرامپت ابری ابتدای همین README استفاده کنید. پرامپت
زیر برای نصب محلی با Docker، توسعه یا زمانی است که از قبل سرور و دامنه دارید.

متن زیر را به ChatGPT، Codex، Claude یا یک دستیار برنامه‌نویسی دیگر بدهید. اگر هوش مصنوعی به سیستم شما دسترسی ندارد، خروجی هر دستور را برایش ارسال کنید.

```text
تو دستیار راه‌اندازی من برای نسخه فارسی/انگلیسی وب‌سایت self-hosted زیر هستی:
https://github.com/Jenesyx/opengym-fa

هدف: برنامه را نصب کن، عملکرد آن را از ابتدا تا انتها بررسی کن و سپس روش استفاده را به من نشان بده. تا زمانی که خود وب‌سایت و مسیر /api/health پاسخ صحیح نداده‌اند، اعلام موفقیت نکن.

ابتدا این موارد را از من بپرس:
1. سیستم‌عامل من Windows، macOS یا Linux است؟
2. نصب سریع محلی، محیط توسعه کد یا انتشار عمومی با HTTPS می‌خواهم؟
3. آیا Docker همراه Compose نصب است؟
4. اگر انتشار عمومی می‌خواهم، دامنه دقیق من چیست و از کدام reverse proxy یا tunnel استفاده می‌کنم؟

روش پیشنهادی نصب عادی:
1. مخزن https://github.com/Jenesyx/opengym-fa.git را clone کن و وارد پوشه opengym-fa شو.
2. با دستور مناسب سیستم‌عامل، .env.example را به .env کپی کن.
3. برای localhost مقادیر RP_ID=localhost و ORIGIN=http://localhost:8080 را نگه دار.
4. دستور docker compose up -d --build را اجرا کن.
5. docker compose ps و لاگ سرویس‌های ناموفق را بررسی کن.
6. مطمئن شو http://localhost:8080 کد HTTP 200 می‌دهد و http://localhost:8080/api/health شامل ok: true است.
7. اگر پورت اشغال بود، یک WEB_PORT آزاد انتخاب کن و ORIGIN را نیز با همان پورت هماهنگ کن.

برای توسعه کد، ابتدا Node.js 20.19+ یا 22.12+ را بررسی کن و سپس در ریشه مخزن npm install و npm run dev را اجرا کن. آدرس چاپ‌شده فرانت‌اند را بخوان؛ اجراکننده پروژه در صورت اشغال‌بودن پورت API، پورت دیگری انتخاب می‌کند.

برای انتشار عمومی، HTTPS را الزامی بدان. RP_ID باید فقط hostname باشد، مانند gym.example.com، و ORIGIN باید آدرس کامل و دقیق، مانند https://gym.example.com، باشد. توضیح بده که تغییر RP_ID، Passkeyهای قبلی را نامعتبر می‌کند. بر اساس انتخاب من Cloudflare Tunnel، Caddy، Traefik، nginx یا Nginx Proxy Manager را تنظیم کن.

قوانین ایمنی و بررسی:
- هرگز محتوای .env، فایل data/secret، فایل data/db.json، Passkey، cookie یا کلید خصوصی را چاپ یا آپلود نکن.
- قبل از نصب نرم‌افزار سیستمی، تغییر DNS یا firewall، حذف داده یا جایگزینی تنظیمات از من اجازه بگیر.
- پوشه ./data را حفظ کن و پیش از به‌روزرسانی یا تغییر پرریسک، روش پشتیبان‌گیری را توضیح بده.
- خطای واقعی، محیط اجرا و خروجی دستورها را بررسی کن و حدس نزن.
- اگر دستوری شکست خورد، هر بار فقط یک دستور بعدی بده و دقیق بگو کدام خروجی را برایت ارسال کنم.

پس از نصب، مرحله‌به‌مرحله این موارد را آموزش بده:
- ساخت پروفایل Passkey یا استفاده از حالت مهمان؛
```
